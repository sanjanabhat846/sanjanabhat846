## 🚀 Featured Projects

### 🌱 AgriSense AI — Plant Disease Detection & Advisory System

An AI-powered plant disease detection system that classifies plant leaf images into 38 disease classes and provides comprehensive disease information and advisory recommendations.

- **Technologies:** `Python` • `TensorFlow` • `Keras` • `EfficientNetB0` • `Flask` • `PlantVillage Dataset`
- **Key Highlights:**
  - Trained on the **PlantVillage dataset** with **38 plant disease classes**
  - Utilized **transfer learning with EfficientNetB0** and data augmentation for high classification accuracy
  - Generates top prediction with a confidence score
  - Displays detailed disease description, symptoms, treatment, and prevention measures
  - Built as a user-friendly **Flask-based web application**
- 🔗 **Repository:** [AgriSense-AI](https://github.com/sanjanabhat846/AgriSense-AI)

---

### 🤖 AI Support Agent — Local-First Support System

A local-first AI support system designed to retrieve relevant information from a knowledge base and generate grounded, verified responses.

- **Technologies:** `Python` • `LangGraph` • `RAG` • `FAISS` • `Hugging Face` • `Ollama`
- **Workflow:** `Retrieval` → `Generation` → `Verification`
- **Key Highlights:**
  - Implements **Retrieval-Augmented Generation (RAG)** using **FAISS** vector similarity search
  - Employs **local LLM inference** via **Ollama** for privacy and offline support capabilities
  - Leverages **LangGraph** for structured verification workflows to reduce unsupported/hallucinated responses
  - Integrates structured knowledge-base retrieval for precise document grounding
- 🔗 **Repository:** [orbitdesk-ai-support-agent](https://github.com/sanjanabhat846/orbitdesk-ai-support-agent)
