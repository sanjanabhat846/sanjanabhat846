## 🚀 Featured Projects

### 🌱 AgriSense AI — Plant Disease Detection & Agricultural Advisory System

An AI-powered plant disease detection system that classifies plant leaf images into 38 disease classes and provides comprehensive disease information and agricultural advisory recommendations.

- **Technology:** `Python` • `TensorFlow` • `Keras` • `EfficientNetB0` • `Flask`
- **Key Highlights:**
  - Trained on the **PlantVillage dataset** across **38 disease classes**
  - Applied **transfer learning with EfficientNetB0** and data augmentation for high accuracy
  - Generates top disease prediction with an exact confidence score
  - Displays detailed disease descriptions, symptoms, treatment options, and prevention guidelines
  - Delivered via an interactive **Flask web application**
- 🔗 **Repository:** [AgriSense-AI](https://github.com/sanjanabhat846/AgriSense-AI)

---

### 🤖 AI Support Agent — Local-First Support System

A local-first AI support system designed to retrieve relevant information from a knowledge base and generate grounded, verified responses.

- **Technology:** `Python` • `LangGraph` • `RAG` • `FAISS` • `Hugging Face` • `Ollama`
- **Workflow:** `Retrieval` → `Generation` → `Verification`
- **Key Highlights:**
  - Implements **Retrieval-Augmented Generation (RAG)** using **FAISS** vector similarity search
  - Leverages **local LLM inference** via **Ollama** for privacy and offline support functionality
  - Employs **LangGraph** verification workflows to eliminate unsupported/hallucinated responses
  - Architected as a privacy-focused **local-first AI support system**
- 🔗 **Repository:** [orbitdesk-ai-support-agent](https://github.com/sanjanabhat846/orbitdesk-ai-support-agent)
